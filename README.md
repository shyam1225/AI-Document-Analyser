# AI Document Analyzer

An AI-powered document analyzer built using Flask, FAISS, Sentence Transformers, and OpenRouter.

## Features

- Upload multiple PDFs, DOCX, TXT, and Images
- Semantic search using FAISS
- AI-powered question answering
- Conversation history
- Markdown rendering
- Chart generation using Chart.js
- HTML table rendering
- Image OCR support

## Tech Stack

- Flask
- Sentence Transformers
- FAISS
- OpenRouter
- Chart.js
- HTML/CSS/JavaScript

## Installation

```bash
pip install -r requirements.txt
```

Create a `.env` file:

```
OPENROUTER_API_KEY=your_api_key
```

Run:

```bash
python main.py
```
